# PRD

## 목표

코드만으로 파악하기 어려운 DawnHolder의 구조를 `_index.html`에서 시각적으로 탐색한다.

## 핵심 기능

- 레이어 → 폴더 → 네임스페이스 → 타입 계층 탐색
- 클래스, 인터페이스, 구조체, enum 관계 표시
- 메서드 호출과 역호출을 호출 스택처럼 단계적으로 탐색
- 상속, 구현, 사용 의존성의 양방향 탐색
- SOLID와 프로젝트 디자인 규칙 기반 설계 냄새 표시
- 생성 코드 필터
- 원본 코드가 바뀌면 한 명령으로 데이터 재생성

## 제외 범위

- TDD 단위·통합 테스트 코드의 아키텍처 집계
- 헤드리스 봇 시나리오와 PacketGenerator 이외 개발 도구의 아키텍처 집계
- 런타임 프로파일링 및 실제 호출 빈도 측정
- SOLID 위반의 자동 확정
- 원본 소스 자동 리팩터링
- Unity scene/prefab 직렬화 그래프 분석
- 외부 서버나 데이터베이스 의존
